Northwind is installed in namespace {{ .Release.Namespace }}.

Check pods:
  kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

{{- if .Values.ingress.enabled }}

Wiki URL: https://{{ .Values.ingress.host }}
  (DNS for {{ .Values.ingress.host }} must point to the ALB:
   kubectl get ingress {{ .Release.Name }}-wiki -n {{ .Release.Namespace }})
{{- else }}

Open the wiki:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ .Release.Name }}-wiki 8088:{{ .Values.wiki.service.port }}
  then browse to http://127.0.0.1:8088
{{- end }}

The RAG API is internal only: http://{{ .Release.Name }}-rag:{{ .Values.rag.service.port }}
Re-index after big changes:
  kubectl exec -n {{ .Release.Namespace }} deploy/{{ .Release.Name }}-rag -- python -m app.ingest

Secret "{{ .Values.secrets.existingSecret }}" must contain:
  OPENAI_API_KEY, ANTHROPIC_API_KEY (optional), WIKI_API_TOKEN, RAG_API_TOKEN
